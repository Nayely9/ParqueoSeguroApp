# ParqueoSeguroApp

Aplicación móvil multiplataforma para la gestión de parqueaderos, desarrollada como proyecto integrador de Ingeniería en Tecnologías de la Información y Comunicación.

La aplicación permite a los usuarios registrarse, iniciar sesión, administrar sus vehículos, consultar parqueaderos, visualizar zonas disponibles y realizar reservas de espacios de estacionamiento.

El proyecto está compuesto por una aplicación móvil desarrollada con Flutter y un backend desarrollado con Python y Flask, conectado a una base de datos MySQL.

# 2. Objetivo del proyecto

El objetivo de ParqueoSeguroApp es proporcionar una aplicación móvil que permita gestionar información relacionada con parqueaderos y facilitar la reserva de espacios disponibles.

La aplicación permite:

- Registrar usuarios.
- Iniciar sesión.
- Administrar vehículos.
- Consultar parqueaderos.
- Consultar zonas de estacionamiento.
- Visualizar la disponibilidad de las zonas.
- Realizar reservas.
- Consultar las reservas realizadas.
- Cancelar reservas.
- Visualizar la ubicación de los parqueaderos mediante un mapa.
